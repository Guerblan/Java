#  Cuatro en Raya — Versión Consola (Java)

Aplicación en Java que permite jugar al clásico **Cuatro en Raya** desde la consola.

Incluye dos modos de juego:
-  Jugador vs Jugador
-  Jugador vs Máquina (movimientos aleatorios válidos)

---

##  Requisitos
Para ejecutar el proyecto necesitas:
- **Java 20** o superior instalado

---

## ▶ Ejecución rápida

Compilar:

```bash
javac Main.java

Ejecutar:

```bash
java Main

```
