# Conversor CSV / JSON / XML

Programa en Java para convertir ficheros entre los formatos CSV, JSON y XML desde la consola.

Permite:
- Seleccionar una carpeta con ficheros
- Leer un fichero según su extensión (.csv, .json, .xml)
- Convertirlo a otro formato
- Guardar el resultado en la misma carpeta

## Requisitos
- Java 20 o superior
- Consola o terminal
- Ficheros con formato CSV, JSON o XML

## Ejecución
Compilar y ejecutar desde la carpeta del proyecto:

javac -encoding UTF-8 -d bin src/App.java
cd bin
java App

## Estructura del proyecto
src/controlador -> Controlador del programa
src/modelo -> Manejo de archivos y datos
src/vista -> Entrada y salida por consola
App.java -> Punto de inicio
